# Первая курсовая работа: анализ транзакций

Приложение для анализа банковских транзакций из Excel-файла.
Генерирует JSON для веб-страниц, формирует Excel-отчёты, предоставляет сервисы.

## Стек
- Python 3.14
- pandas, requests, openpyxl
- pytest, flake8

## Установка
poetry install

## Запуск
python -m src.main

## Тесты
pytest
